## 0.3.1

- 保存外接屏优先的持久拓扑，唤醒到登录窗口时不再先点亮内建屏
- 外接屏断开时使用对应的持久恢复，确保内建屏下次登录仍可用
- 缩短最后一台外接显示器断开后的硬件确认和内屏亮度恢复等待
- Power 在面板打开时先刷新功率分流，再补齐电池慢速详情
- 修复拔掉最后一台外接显示器后内建显示器未自动恢复的问题
- 增加 Apple Silicon IOKit 显示硬件监听，避免 WindowServer 漏报物理拔线
- 恢复判断同时使用硬件服务数量与系统活跃显示器列表，并保留低开销拓扑安全检查
- 多外屏和快速重插会重新确认外接硬件服务，不会误恢复内建屏
- 后台断开检查不再触发主界面恢复按钮的进度动画
- 内建显示器恢复后将亮度设为 35%

## 0.3.0

- 内建显示器关闭改为优先从当前显示布局中断开，私有接口不可用时自动回退到镜像黑屏
- 增加 IOKit 早期唤醒监听和短周期恢复，减少外接屏唤醒时内建屏闪亮
- Codex 面板显示所有执行中对话的名称及计划完成进度，仅读取本地会话索引和增量日志
- 每次打开面板都会立即请求最新 Codex 额度，设置中的间隔仅控制面板保持打开时的后续刷新
- 鼠标按键映射支持为每个按钮录制并保存自定义快捷键
- 单条锁屏时间可以暂停，保留内容且不参与锁屏、冲突检测或定时调度

## 0.2.9

- 鼠标未连接时停止按钮接管和 HID++ 监听，使用设备到达通知恢复
- 鼠标 DPI 读取和写入改为串行执行，避免旧结果覆盖新设置
- 网络在面板关闭时自动休眠，菜单栏圆环使用网络时除外
- 修正电池功率方向、网络计数器复位和测试宿主硬件隔离
- 统一应用版本读取并进一步清理同步硬件调用
- 内建显示器亮度滑杆在面板打开时同步系统实际亮度
- 原生亮度读写按显示器串行，避免过期读数覆盖刚写入的值
- 外接显示器只探测已启用的 DDC 控制项，减少无效通信和超时
- Release 在创建前验证 tag 与应用版本一致，并运行完整测试
