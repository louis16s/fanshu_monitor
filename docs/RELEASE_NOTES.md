## 0.2.9

- 鼠标未连接时停止按钮接管和 HID++ 监听，使用设备到达通知恢复
- 鼠标 DPI 读取和写入改为串行执行，避免旧结果覆盖新设置
- 网络在面板关闭时自动休眠，菜单栏圆环使用网络时除外
- 修正电池功率方向、网络计数器复位和测试宿主硬件隔离
- 统一应用版本读取并进一步清理同步硬件调用
- 内建显示器亮度滑杆在面板打开时同步系统实际亮度
- 原生亮度读写按显示器串行，避免过期读数覆盖刚写入的值
- 外接显示器只探测已启用的 DDC 控制项，减少无效通信和超时
- Release 在创建前验证 tag 与应用版本一致，并运行完整测试
