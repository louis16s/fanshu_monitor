一枚常驻菜单栏的精密小仪表：看 CPU、GPU、内存、电池，也用 F1/F2 控制鼠标所在外接屏的亮度。

External Display Control

让外接屏像内建屏一样顺手。

鼠标在哪块可控外接屏上，F1/F2 就调哪块屏。不可控屏和内建屏会交回 macOS，保留系统原生行为。

F1

按鼠标位置分配亮度目标

应用拦截系统亮度键后，会根据当前鼠标所在屏幕匹配显示器能力；只有在可 DDC 控制的外接屏上才消费事件。

OSD

系统原生亮度浮层

调整亮度时使用 macOS 原生 OSD，并尽量显示在被调整的那块显示器上。

DDC

能力与原因透明

每个控制项都会显示可用状态；如果显示器、线缆或系统路径不支持，会给出不可控原因。

↻

插拔自动刷新

监听屏幕参数和显示器重配置事件，外接屏插拔后自动重扫，不需要重启应用。

System Monitoring

一眼看出机器现在忙不忙。

01

CPU / GPU 实时状态

CPU 占用、温度、GPU 利用率和显存数据都放在可快速扫读的位置。

02

内存开销可观察

显示 App 自身内存占用、缓存和压缩内存，方便判断常驻成本。

03

电池与网络按需加载

适配器、健康度、循环数、温度、SSID、IPv4/IPv6 等较重数据只在需要时采样。

Settings

设置页也保持清楚和克制。

更新检查放在关于里；鼠标页集中管理 MX Anywhere 3S 的按键映射、DPI 读取和 DPI 设定。

Performance Defaults

常驻可以丰富，但不能吵。

番薯Monitor 的默认策略是少做无意义采样：隐藏模块停止采样，面板关闭时降低刷新频率，重数据缓存并按需刷新。

Get 番薯Monitor

下载，解压，放进你的菜单栏。

当前版本面向 Apple Silicon 和 macOS 26+。如果 macOS 拦截未公证应用，可在终端清除隔离属性后打开。
