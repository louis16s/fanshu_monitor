Q&A

常见问题

安装前最常被问到的几件事

为什么需要辅助功能权限？＋

F1/F2 接管和鼠标按键映射需要监听系统输入事件。番薯Monitor 只在相关功能开启时使用这项权限，不会记录键盘输入内容。

所有外接显示器都能控制亮度吗？＋

显示器、线缆和连接方式需要支持 DDC/CI。应用会逐台检测，并明确显示不可控原因；不可控时亮度键会交还 macOS。

会不会一直占用很多 CPU？＋

隐藏模块停止对应采样，面板关闭后降低非必要刷新频率，SSID、DDC、HID 和电池重遥测等数据按需读取并缓存。

自动锁屏会先进入屏幕保护吗？＋

不会。启用番薯Monitor 的时间策略后，到达闲置时间会直接请求系统锁定，登录后策略会继续运行。

支持哪些 Mac？＋

当前版本面向 Apple Silicon Mac，最低系统版本为 macOS 26.0。
