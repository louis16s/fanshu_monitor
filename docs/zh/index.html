External Display

外接屏亮度，终于像内建屏一样顺手。

鼠标在哪块可控外接屏上，亮度键就调哪块屏。内建屏和不可控外接屏会交回 macOS。

F1

目标跟随鼠标

通过屏幕位置匹配当前鼠标所在显示器，只在可 DDC 控制的外接屏上消费亮度键事件。

OSD

系统浮层

调整亮度时尽量调用 macOS 原生亮度 OSD，并显示在正在调整的屏幕上。

DDC

原因透明

显示每台屏幕的控制状态、DDC 读写状态，以及不可控原因。

↻

自动刷新

监听显示器插拔和屏幕参数变化，自动重扫显示器能力。

System Monitoring

常驻监控，但不把机器吵醒。

01

核心指标优先

CPU、GPU、内存、电池和显示器状态放在主面板，标题和数字便于快速扫读。

02

开销可见

内存面板显示 App 自身占用，方便判断常驻成本是否合理。

03

重数据按需加载

DDC、SSID、电池遥测、鼠标 DPI 等数据按可见性和需要读取。

Settings

设置也保持清楚、短路径。

关于里检查更新，Codex 管理刷新间隔，鼠标页集中管理按键、DPI 和省电读取策略。

Performance

功能丰富，但采样克制。

隐藏模块停止采样，面板关闭后降低刷新频率，较重数据缓存并按需刷新。

0隐藏模块继续采样的理由
5s低频菜单栏刷新目标
按需DDC、SSID、鼠标 DPI
