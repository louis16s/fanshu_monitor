# 外接显示器空闲策略

未连接外屏时自动暂停外屏专用功能，不修改用户保存的开关；接入后按原设置恢复。主界面内屏亮度控制继续可用。

## 已调整

- 外屏不存在时不启动 F1/F2 接管，不因接管开关单独加载显示器硬件监听
- 仅打开内屏面板时也不注册外屏 IOKit 硬件及提前电源事件监听；有内屏恢复需求时例外保留
- 不请求外屏音量、对比度与能力探测；内屏亮度仍按原有面板需求与 0.2 秒间隔同步
- 仅对分类为 `externalDDC` 的显示器加载、匹配 DDC 桥；仅有内屏、Apple 原生亮度屏或虚拟屏时不加载 DDC
- 最后一个 DDC 屏移除后，一次事件驱动的轻量发现负责释放旧 DDC 服务和范围缓存，不新增轮询
- 已断开的旧显示器行不能触发新的 DDC 写入或重新加载桥
- 内屏亮度同步需求不变时复用已有任务，不再每次显示器刷新都取消并重建
- 保留系统屏幕拓扑通知；仍有内屏关闭/恢复需求时保留硬件断开与睡眠唤醒监听，避免节能策略破坏恢复功能

## 其他性能检查

- 面板保留内容用于快速打开；面板关闭时采样层仍按既有需求释放工作器，动画仍由可见性控制
- Codex 活动任务只在面板可见且已启用时读取，记录/标题缓存有上限；额度刷新间隔、加速刷新和到期刷新规则未调整
- Gamma 硬件读写在后台串行队列执行，窗口操作回到主线程
- 菜单栏所需的轻量采样、鼠标映射、锁屏和内屏恢复不是可随面板关闭的功能，继续保留
- 显示器能力查询与硬件拓扑注册仍涉及主线程的系统 API，真实插拔延迟及长期内存需要 Instruments/真实硬件验证；本次静态检查不能证明零开销或给出 CPU 降幅

## 验证

自动测试覆盖无外屏关闭面板、有内屏打开面板、待恢复内屏、外屏重新接入及 DDC 缓存重复释放。真实显示器断开、重连、锁屏登录和睡眠唤醒仍需硬件验证。
