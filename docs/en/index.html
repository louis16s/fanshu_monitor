Fanshu Monitor

A precise little instrument in your macOS menu bar: watch CPU, GPU, memory, and battery while using F1/F2 to control the external display under your pointer.

External Display Control

Make external displays feel built in.

When your pointer is on a controllable external display, F1/F2 adjusts that display. Built-in and unsupported displays pass the event back to macOS.

F1

Brightness target follows the pointer

The app intercepts brightness keys, resolves the screen under the pointer, checks DDC capability, and only consumes events when an external display can actually be controlled.

OSD

Native macOS brightness overlay

Brightness changes use the native system overlay and target the display being adjusted whenever possible.

DDC

Clear capability state

Each display control reports whether it is available. Unsupported monitors, cables, or system paths are explained instead of pretending to work.

↻

Automatic display refresh

Screen parameter and reconfiguration notifications trigger display rescans after connect or disconnect, no app restart required.

System Monitoring

Know whether your Mac is actually busy.

01

Live CPU and GPU state

CPU load, temperature, GPU utilization, and memory readings sit where they are easy to scan.

02

Memory overhead is visible

The panel shows the app's own memory footprint alongside cache and compressed memory.

03

Heavy telemetry loads on demand

Adapter health, cycle count, battery temperature, SSID, IPv4, and IPv6 are sampled only when useful.

Settings

Settings stay clear and restrained.

Update checks live in About, while the mouse page groups MX Anywhere 3S button mapping, DPI reads, and DPI apply controls.

Performance Defaults

Rich enough to help. Quiet enough to stay.

Fanshu Monitor avoids pointless sampling by default: hidden modules stop, panel-closed refresh slows down, and expensive display or network data is cached and loaded on demand.
