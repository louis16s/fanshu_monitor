Q&A

Common questions

The things people usually ask before installing

Why does it need Accessibility permission?＋

F1/F2 takeover and mouse button mapping need access to system input events. Fanshu Monitor only uses this access while those features are enabled and does not record keyboard content.

Can it control every external display?＋

The display, cable, and connection must support DDC/CI. Each display is classified independently, with a clear reason when control is unavailable.

Will it use a lot of CPU in the background?＋

Hidden modules stop sampling. Expensive reads such as SSID, DDC, HID, and battery telemetry run on demand and use caches.

Does scheduled locking start the screen saver first?＋

No. When a schedule is active, the app requests the system login lock directly and resumes policy evaluation after login.

Which Macs are supported?＋

The current release targets Apple Silicon Macs running macOS 26.0 or later.

Is it free?＋
