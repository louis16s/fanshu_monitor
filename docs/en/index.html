External Display

Make external brightness feel built in.

When the pointer is on a controllable external display, brightness keys target that display. Built-in and unsupported displays pass back to macOS.

F1

Pointer-based targeting

The app resolves the screen under the pointer and only consumes brightness key events when the external display is DDC controllable.

OSD

Native overlay

Brightness changes use the native macOS OSD whenever possible and target the display being adjusted.

DDC

Clear reasons

Each display reports control state, DDC read/write status, and why a control is unavailable.

↻

Auto refresh

Display connect, disconnect, and parameter changes trigger a display capability rescan.

System Monitoring

Always visible, carefully sampled.

01

Core metrics first

CPU, GPU, memory, battery, Codex quota, and display state are arranged for fast scanning.

02

Overhead is visible

The memory panel shows the app's own footprint so long-running cost stays easy to judge.

03

Expensive data loads on demand

DDC, SSID, battery telemetry, and mouse DPI data are sampled only when useful.

Settings

Short paths, clear controls.

Update checks live in About. Codex owns its refresh interval. Mouse settings group button mapping, DPI, and power-saving reads.

Performance

Rich enough to help. Quiet enough to stay.

Hidden modules stop sampling, panel-closed refresh slows down, and heavier data is cached until needed.
